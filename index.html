01 Memory Tricks & Mnemonics

Learn these 7 hooks and you will have the whole chapter locked in memory. Each one maps directly to exam problems.

Start Here The Big Picture -- One Paragraph

A particle moving through space has a position vector r (an arrow from the origin to where it is). As it moves, r changes -- the rate of that change is velocity v (always pointing along the path it travels, tangent to the curve). If the path curves or the particle speeds up, v itself changes -- the rate of that change is acceleration a (always pointing toward the inside of the curve).

The entire chapter is this: r to v to a = differentiate and a to v to r = integrate. That's it.

Mnemonic 1 The Derivative Chain -- "Rabbits vs Ants"
Remember This
R → V → A

Say: "Position R, Velocity V, Acceleration A -- each one is the derivative of the one before it"

R
r = Position vector. Where is the particle right now?
d/dt
Differentiate with respect to time to get the next one
V
v = dr/dt = Velocity. Which direction and how fast? Always tangent to the path.
d/dt
Differentiate again
A
a = dv/dt = Acceleration. How is velocity changing? Points to the inside of the curve.
Tip: Go backwards by integrating: integrate a to get v, integrate v to get r. This is exactly how all projectile equations are derived.
Mnemonic 2 Velocity Direction -- "V Hugs the Road"
Golden Rule

Velocity is ALWAYS tangent to the path

V
Velocity hugs the curve -- it points exactly where the particle is heading at that instant
A
Acceleration points toward the INSIDE (concave side) of any curve
Rule
Constant speed + curved path: v is tangent, a is purely perpendicular -- they are 90 degrees apart
Common trap: Students think acceleration = 0 if speed is constant. Wrong! A car at constant speed rounding a curve still accelerates because its direction keeps changing.
Mnemonic 3 Acceleration Components -- "GPS" (Gas, Perpendicular, Steering)
Mnemonic
GPS
G
Gas pedal = a-parallel: tangent to path, changes SPEED. Zero means constant speed.
P
Perpendicular = a-perp: normal to path, changes DIRECTION. Always points inward on a curve.
S
Steering rule: if speed is constant, ALL of a is steering (a-parallel = 0). All acceleration is perpendicular.
Skier problem shortcut: Speeding up = a tilts forward of the normal. Maximum speed = a is purely normal (perpendicular). Slowing down = a tilts backward of the normal.
Mnemonic 4 Projectile Motion -- "HAVE" (Horizontal Always, Vertical Ever-changing)
Projectile
HAVE
H
Horizontal: zero acceleration (ax = 0). No force acts sideways.
A
Always constant horizontal velocity: vx = v0 * cos(angle). Never changes for the whole flight.
V
Vertical: constant downward acceleration, ay = -g = -9.8 m/s^2. Always.
E
Ever-changing vertical velocity: vy = v0*sin(angle) - g*t. Gets smaller going up, zero at peak, negative coming down.
Critical warning: At the peak, vy = 0 BUT acceleration is still -9.8 m/s^2 downward. Acceleration is NEVER zero during flight.
Mnemonic 5 Trig Components -- "CASH" (Cos = Adjacent Side = Horizontal)
Trig Trick
CASH
C
Cosine gives you the...
A
Adjacent side of the right triangle, which is the...
S
Side that runs along the...
H
Horizontal. So: vx = v0 * cos(angle), and vy = v0 * sin(angle)
Mnemonic 6 Problem-Solving Order -- "TPVR" (Time, Position, Velocity, Result)
Strategy
TPVR
T
Time first. t is the bridge between x and y. Always find it from the vertical equation first.
P
Position. Once you have t, find x = vx*t and y = vy0*t - 0.5*g*t^2
V
Velocity. vx = vx0 (unchanged!), vy = vy0 - g*t
R
Result. Combine: speed = sqrt(vx^2 + vy^2), angle = arctan(vy/vx). Check quadrant!
Mnemonic 7 Skier Points -- "Straight, Ahead, Normal, Behind" (SANB)
Skier Problem

For the ski-jump ramp problem (points B, D, E, F), remember acceleration direction at each point:

B
Straight ramp + speeding up: a is parallel to path (forward/tangent direction)
D
Curved + speeding up: a points ahead of the normal (inward and forward)
E
Curved + max speed (dv/dt = 0): a is purely normal -- perpendicular, pointing inward
F
Curved + slowing down: a points behind the normal (inward and backward)
Hook: B = Straight along path. D = Ahead of normal. E = Normal only. F = Behind normal. "B D E F = Straight, Ahead, Normal, Behind"

03 Key Concepts -- Deeply Explained

These are the conceptual questions that separate high marks from average marks. Read each one carefully.

Why is instantaneous velocity ALWAYS tangent to the path?▼

Picture two points P1 and P2 on the curve. The average velocity points in the same direction as the displacement vector (straight arrow from P1 to P2).

Now shrink the time interval: slide P2 toward P1 along the curve. The straight arrow from P1 to P2 keeps rotating until it lines up perfectly with the tangent at P1. In the mathematical limit as delta-t approaches zero, that is your instantaneous velocity.

v = lim[dt->0] (delta_r / delta_t) = dr/dt // This limit IS the tangent direction at P1

Exam application: If a question shows a curved path and asks which way the particle is moving at a specific point -- draw the tangent line at that point. The velocity vector points along that tangent.

Why can a particle accelerate at CONSTANT speed?▼

Acceleration means the velocity vector is changing. A vector has two parts: its size (speed) AND its direction. Acceleration changes when either part changes.

When a car drives a roundabout at constant 40 km/h, the speedometer doesn't move. But the direction of the car keeps changing -- the velocity vector keeps rotating. A rotating vector is a changing vector. Change per unit time is acceleration.

Speed constant -> a_parallel = 0 (no speed change) Curved path -> a_perp != 0 (direction is changing) Total accel -> NOT zero! (it just has no "gas pedal" component)

Rule to remember: Constant speed never means no acceleration when the path is curved.

How do we prove the projectile path is a parabola?▼

Start with both position equations:

x = (v0*cos(a0)) * t ... (1) y = (v0*sin(a0))*t - (1/2)*g*t^2 ... (2)

From equation (1), isolate t:   t = x / (v0*cos(a0))

Substitute into equation (2):

y = (v0*sin(a0)) * [x / (v0*cos(a0))] - (1/2)*g * [x/(v0*cos(a0))]^2 Simplify sin(a)/cos(a) = tan(a): y = tan(a0)*x - [g / (2*v0^2*cos^2(a0))] * x^2

This has the form y = B*x - C*x^2 where B and C are just constants. That is a quadratic equation in x -- which is a parabola opening downward.

The Monkey and Zookeeper -- why does the dart ALWAYS hit?▼

A monkey hangs at distance d. A dart is aimed directly at the monkey. The monkey drops the instant the dart is fired. Why does it always get hit?

Core insight: Gravity pulls both objects down by the same amount at the same time.

Without gravity: dart travels straight line directly to monkey's start position. With gravity: BOTH fall by exactly (1/2)*g*t^2 below their "no gravity" positions. y_dart = d*tan(a0) - (1/2)*g*t^2 y_monkey = H - (1/2)*g*t^2 [where H = d*tan(a0)] The -(1/2)*g*t^2 term is IDENTICAL for both. They are always at the same height. They always meet.

The dart speed only affects WHEN they meet (sooner or later) -- not WHETHER they meet.

Sled at the crest of a hill -- which way does acceleration point?▼

The sled slows going up, is fastest at the crest, then speeds up going down. At the crest, the speed is at its maximum value -- meaning it is momentarily not increasing or decreasing.

At the crest: dv/dt = 0 -> a_parallel = 0 (speed not changing at this instant) path curves downward (concave down) -> a_perp points toward center of curvature = STRAIGHT DOWN

Answer: acceleration points straight downward at the crest (vector 7 in the textbook).

Why straight down and not at an angle? Because a_parallel = 0 exactly at the crest (speed is at a local maximum -- neither increasing nor decreasing). The only remaining acceleration is the centripetal one pointing to the inside of the curve, which at the top of a hill is directly downward.
Average vs. Instantaneous velocity -- what is the real difference?▼
Average velocity = (total displacement) / (total time) = points from start to end position = ignores what happened along the way Instantaneous vel. = dr/dt = limit as dt -> 0 = tangent to path at that exact moment = what a speedometer + compass shows right now

They are almost never equal during curved motion. Average velocity only cares about where you started and where you ended up. Instantaneous velocity tells you the exact direction and speed at one single moment.

Exam language guide: "at t = 2.0 s" means instantaneous. "between t = 0 and t = 2.0 s" means average.
04 Projectile Motion -- Complete Playbook

Three problem types. Master these and you can solve any projectile question on the exam.

Foundation The Two Independent Motions

Horizontal (x-axis)

  • ax = 0 -- no horizontal force
  • vx = v0*cos(angle) -- constant, never changes
  • x = vx * t -- just speed times time
  • Equal x-distances every second

Vertical (y-axis)

  • ay = -g = -9.80 m/s^2 -- always
  • vy = v0*sin(angle) - g*t
  • y = vy0*t - (g/2)*t^2
  • vy = 0 only at the peak
The bridge: Time t is shared between both axes. Find t from the vertical equation, then plug it into the horizontal equation.
Steps Universal Problem-Solving Approach
Draw a clear diagram and list all known values
Origin at launch point. +x right, +y up. Write down: v0, launch angle, starting height, landing height, any given time.
Decompose the initial velocity into components
vx0 = v0 * cos(angle). vy0 = v0 * sin(angle). Exception: horizontal launch means angle=0, so vx0=v0 and vy0=0.
Identify the target: position, velocity, time, or range?
Write the target variable explicitly before choosing an equation. This prevents picking the wrong one.
Find time from the vertical equation (almost always first)
Set y = final height. If landing at same height: t_total = 2*vy0/g. If different height: solve the quadratic -- take only the positive root.
Use t in the horizontal equation
x = vx0 * t. That is all there is for horizontal position. It is always this simple.
Find velocity components and combine them
vx = vx0 (same as always). vy = vy0 - g*t. Speed = sqrt(vx^2 + vy^2). Angle = arctan(vy/vx) -- verify the correct quadrant!
Case 1 Horizontal Launch (Thrown off a cliff)

Object launched perfectly horizontally. Launch angle = 0 degrees. Example: motorcycle off a cliff, package dropped from plane.

Given: v0 (horizontal speed), height H above ground Setup: vx0 = v0, vy0 = 0 (no vertical component at launch) Find time to hit ground (y = -H): -H = 0 - (1/2)*g*t^2 t = sqrt(2H / g) Find horizontal distance: x = v0 * t = v0 * sqrt(2H/g) Find velocity at impact: vx = v0 (unchanged the whole way down) vy = -g*t (negative means downward) speed = sqrt(vx^2 + vy^2)
Example numbers: v0=9.0 m/s, t=0.5s: x = 9.0*0.5 = 4.5m, y = -0.5*9.8*0.25 = -1.2m (below the cliff)
Case 2 Symmetric Launch (Lands at same height)

Launched at angle a0, lands at the same height. Perfect parabola. Example: baseball, football, soccer kick.

Decompose: vx0 = v0*cos(a0), vy0 = v0*sin(a0) Time to peak (set vy = 0): t_peak = vy0 / g Max height: h = vy0^2 / (2*g) Total flight time (symmetric path): t_total = 2 * t_peak Range: R = vx0 * t_total OR: R = v0^2 * sin(2*a0) / g (shortcut formula) // 45 degrees maximizes R because sin(2*45) = sin(90) = 1 (maximum) // 30 and 60 degrees: sin(60) = sin(120) = same value, so same R
Case 3 Different Landing Height (Quadratic needed)

Lands at a different height than launch. Requires quadratic formula. Example: grasshopper off a cliff, projectile over a wall.

Set up: y_final = vy0*t - (1/2)*g*t^2 Rearrange to standard form: (1/2)*g*t^2 - vy0*t - y_final = 0 // if landing below: y_final is negative, so -y_final is positive Use quadratic formula: t = [vy0 +/- sqrt(vy0^2 + 2*g*|y_final|)] / g IMPORTANT: Take only the POSITIVE root. // Negative time is physically impossible. Discard it. Then find horizontal distance: x = vx0 * t
Most common mistake: Students forget there are two roots from the quadratic formula and pick the wrong one. Always check -- you want the positive time value.
